CLI 现在提供短命令入口和逐级菜单。进入菜单后选择编号即可操作，不需要记住内部设置 ID、长参数或发现引用。

设备连接、等待主机授权和失败原因也会显示在原生远程桌面页；收到画面后，该页面预览同一画面，
“打开画面与键鼠窗口”进入控制窗口。接收端首次授权和系统权限仍由设备所有者确认。

| 入口 | 用途 |
| --- | --- |
| `/setting`、`/settings` | 通用、网络、设备、文件传输、远程桌面、系统监控、权限、高级 |
| `/setting 网络` | 直接进入分类；英文分类名也可用 |

选定设备后，切换菜单会保留目标。没有目标的设备操作会先引导选择；返回或跳转会取消尚未执行的操作。文件路径支持空格及成对引号，不执行 shell 展开。

## 设置如何生效

分类和名称沿用原生设置界面；当前只列出已接入 CLI 的设置及操作，并非已经覆盖全部 GUI 设置。

本机八项可修改设置为：顶部栏 IP 归属地、网络速度、网络延迟，实时 FPS 显示，详细日志、日志级别，远程画面帧率和分辨率。菜单展示当前值，选择后展示修改前后对比，确认后通过原生接口保存并独立读回。确认前若发现值被其他操作改动，会拒绝使用旧值继续写入。协议签名算法和 X-Wing 偏好只读；握手套件使用原有受约束的 `/handshake` 流程。

远程画质设置在下次启动采集时生效。CLI 启动观看窗口、显示首帧、发送输入尚未接入。系统监控分类目前包含 FPS 显示和服务状态，不提供 CPU／内存指标；权限分类目前管理配对设备的 CLI 委托，不代替 macOS 系统权限设置。

## USB 和文件

本轮修复中的 USB 菜单先选择物理设备，再从 Mac 原生信任存储选择已配对的 SkyBridge 身份，不再依赖局域网发现记录。菜单中的名称仅供选择；连接时仍核验稳定协议身份及完整指纹。冲突或不可用的身份会显示原因，不能选择。首次未配对设备仍需完成原生身份核对，USB 序列号本身不构成信任。

本轮菜单的连接与 `/connect` 重连均发起新的 USB 握手，成功后保存新返回的会话引用。连接失败会保留所选公开身份供再次连接，但清除操作目标，阻止后续文件操作误用旧设备；不会自动重发文件或切到局域网。菜单另提供“打开设备上的 SkyBridge”，使用已安装的 Apple 开发工具正常激活应用，适合对端应用被挂起的情况；这一步不等于已认证连接。设备仍须解锁并信任 Mac，旧版开发工具不支持结构化输出时会明确报错。此前复用连接的实现与失败记录仍保留在旧验证目录中。

普通 `/device` 连接入口也会等待旧会话的确切所有权释放后再建立新连接，按原有策略优先使用 USB。正在传输或处理审批时拒绝重连，避免打断未完成工作。

对应脚本接口为：

```sh
skybridge crossnet usb devices --json
skybridge crossnet usb peers --json
skybridge crossnet usb wake UDID --json
skybridge crossnet usb connect UDID --peer-id PAIRED_UUID --expected-fingerprint FULL_SHA256 --json
```

`/file` 继续使用接收端拥有的审批和回执。首次委托仍需接收端确认；已保存委托后，逐文件选择留在终端。进度达到 100% 后仍会等待接收回执，最终成功消息明确包含校验结果。
