# ADR-0002: 远程控制的身份授权与会话所有权

**状态：** 已接受的行为与安全边界；实现和真机验收分别记录

**日期：** 2026-09-08

**范围：** macOS、iOS/iPadOS、Windows、Android 的共享观看、一控多、输入交接和信任提交

**关联：** [ADR-0001](ADR-0001-SkyBridge-Core-Transport-Matrix.md)、[核心分层](CoreLayering.md)、[共享观看与输入权](RemoteControl-SharedViewing.md)、[多主机工作区](RemoteControl-MultiHost-Workspace.md)

## 背景与威胁模型

设备发现名称、网络端点、协议身份和输入权属于不同边界。历史 UUID、`id:` 与 Bonjour 条目可能同时存在；字符串能够匹配，并不证明记录使用同一个签名身份。仅凭名称、别名或较新的时间戳合并记录，可能使一个对端继承另一条记录的 KEM、旧密钥或证明，也可能错误删除另一条持久授权。

多个已连接观看端还可能保留旧的键盘、鼠标和剪贴板事件。输入交接若只修改界面上的当前设备，旧队列或旧连接仍可能向主机注入操作。

这些是网络身份和权限边界。防护复用现有签名、握手、批准上下文、会话代次和输入租约，不额外创建密码学机制或平行协议。普通界面状态不因此增加密码学保护。

## 决策

### 身份记录与持久提交

- 只有当前认证路径提供的直接身份可以选择待更新的授权记录。发现名称和远端别名仅作为元数据，不能提供另一条记录的密钥或证明。
- 先验证算法、公钥长度及已有的算法域分离指纹，再处理记录选择和冲突。公钥一致性检查不得改成裸公钥哈希或跨算法比较。
- 同一直接身份命中多个有效记录时，不能使用任意第一条、最新时间戳或存储顺序决定身份。不同有效密钥、撤销或无法证明一致的声明继续拒绝。
- 若要收敛别名，必须有当前签名身份与有效批准证据，并明确哪些记录允许更新或清理。不能把全部 `knownDeviceIds` 当作可删除授权清单。
- 本决策不授权手工清空信任存储、解配对或替换 pin。需要身份迁移时，先提交迁移的身份依据、旧记录处理方式、失败行为和回滚边界；保留未解决冲突，不能用自动重试或默认成功掩盖。
- 信任解析返回有类型的拒绝原因。配对边界分别呈现身份材料无效、身份冲突、取消和存储失败；身份冲突不得报告成普通写入故障。 界面显示实际结果，不能根据“存在提示文本”推导授权成功。
- 拒绝发生在持久提交之前时，不留下永久允许策略或派生引导缓存。已完成的权威提交与提交后的别名／缓存清理错误必须区分，不能声称已回滚实际保存的授权。
- 批准上下文绑定原事务、完整 transcript、算法、公钥和身份声明，且只能消费一次。代次或传输已替换的提交必须在持久化前拒绝。

当前 Mac 修正收敛了拒绝结果和配对提示，没有增加自动合并冲突记录的实现。未证明一致的历史记录仍会阻断连接，这是保留的安全边界。

### 多主机与多个观看端

- 产品行为为“多端连接、单端输入、明确交接”。观看批准与输入权分别管理；每个观看端都需要主机批准。
- 每条主机会话独立拥有连接、握手状态、配置事务、解码器、音频状态、输入队列和取消生命周期。连接中、握手中及等待批准的会话都占用容量。
- 只有认证完成且收到确切配置事务的 ACK 才进入已连接状态。收到首帧是独立的媒体验收条件。
- 输入事件入队时固定当前连接和租约，不在发送时为旧事件补上新租约。观察者不能发送键鼠或剪贴板操作。
- 交接顺序为撤销旧输入、释放已按下的控制项、等待释放完成，再由主机授予新租约。失败时明确停止交接，不恢复无法确认的旧输入权。
- 当前控制端断开不会自动把输入权交给观察者。关闭一个窗口或断开一台主机，只清理该会话拥有的资源。
- 首次启动时间预算应包含主机批准及有界身份元数据等待；音视频启动看门狗从当前配置的有效 ACK 后开始。重复 ACK 不延长原截止时间，后续重配不重新享有首次批准预算。

### 平台与性能边界

- Mac/iOS 的已验证协议行为是跨端对齐依据。Windows 保留原生桌面约定；Android 使用平台生命周期和权限接口。平台适配不能改变线上身份或输入授权语义。
- iOS/iPadOS 为控制／观看端，不作为系统级被控主机广告。Android 和 Windows 的可用角色以实际入口及设备验收为准，不能由发现列表中出现设备推断。
- 当前共享 LAN 会话与既有独占 WebRTC 会话的输入排他关系必须保持。支持一种传输不表示另一种传输已完成共享观看。
- 性能不佳时先使用已有节能模式并关闭实时天气 API。装饰绘制暂停、远控视频绘制和窗口生命周期分别验证；性能修复不得随意改变既有视觉效果或绕过权限。
- 连接、发送队列、帧投递和重试都有容量或截止时间；旧会话的迟到回调不得作用于替换后的会话。窗口消失不能单独证明网络、采集、音频或绘制资源已释放。

## 模块归属

| 职责 | 现有归属 |
| --- | --- |
| 共享线格式、配置事务与输入租约 | `SkyBridgeProtocolCore` |
| Mac 信任解析、签名持久提交及清理 | `TrustSyncService` |
| Mac 本机批准上下文、一次性提交和用户提示 | `PairingTrustApprovalService` |
| 平台传输、解码和会话资源 | 各平台已有远控运行时及工作区 |
| 本机批准、观察者状态及交接入口 | 各平台已有界面与批准协调器 |

修复优先复用上述边界。新增模块须有单一职责、明确调用方和行为测试；不新增平行信任存储，不把协议状态塞进界面或进一步扩大大型管理器。

## 验收与迁移要求

| 边界 | 必须保留的证据 |
| --- | --- |
| 身份材料 | 错误长度、跨算法、公钥与指纹不匹配均拒绝 |
| 信任冲突 | 同钥候选、不同钥冲突、伪造别名、撤销及不一致声明分别验证；不借用或删除其他授权 |
| 提交与取消 | 持久化前取消、并发替换、拒绝后无缓存／永久策略、批准不可重放、提交后清理残留 |
| 一控多 | 同一个实际控制端连接两台被控电脑；检查首帧、输入／音频焦点和单会话断开隔离 |
| 多控一 | 两个实际观看端连接同一电脑；只允许一端输入，主机明确交接，检查长按和拖拽释放 |
| 资源与性能 | 核对采集、连接、音频、窗口和回调释放；测量 CPU、GPU、内存及切换延迟 |
| 构建与部署 | 记录源码快照、二进制身份、实际安装和运行进程；构建成功不替代真机或发布验收 |

源码断言随准确的 API 表达调整时，必须保留原有安全不变量，并由行为测试保护。SDK 条件跳过单独列出，不计作通过；协议 parity 的既有基线漂移不能通过自动重写基线消除。

已有协议消息与持久格式保持兼容。本次错误分类修正不引入 schema 迁移。后续若需要身份轮换或记录合并，须先单独说明一致性证明及新旧记录收敛计划，再更新实现与跨端验收。
