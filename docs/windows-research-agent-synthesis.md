## Open Evidence Gaps

- Real Windows-to-mac interop remains blocked until direct LAN, pinned host key, Mac Rust CLI smoke, DNS-SD peer evidence, WebRTC helper proof, and Windows launch smoke all pass locally.
- GitHub branch upload is now covered by the controlled Git Credential Manager fallback plus GitHub refs API audit; SSH remains blocked until the configured SSH public key is authorized on GitHub.
- Interactive WinUI visual screenshots are not suitable for headless CI; they must be generated and archived from an interactive Windows desktop before final UI parity release claims.
